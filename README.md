Maze Adventure AI
Maze Adventure AI is an interactive maze-solving game developed using Python and Tkinter. The project demonstrates the practical application of DFS, BFS, and A* pathfinding algorithms through an engaging and educational gameplay experience.

Features
Random maze generation using Depth First Search (DFS)
Goal placement using Breadth First Search (BFS)
AI solver using A* pathfinding
Multiple challenge levels
Custom maze generation
Hint system
Pause and resume functionality
Progress saving
Achievements and best records
Performance analysis and statistics
Human vs AI path comparison
Algorithms Used
Depth First Search (DFS)
Used to generate unique and solvable mazes.

Breadth First Search (BFS)
Used to locate the farthest reachable cell and place the goal.

A* Algorithm
Used for AI pathfinding and intelligent hints.
